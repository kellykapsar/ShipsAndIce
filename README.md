# Mapping vessel traffic patterns in the ice-covered waters of the Pacific Arctic

This repository contains the code used to process sea ice and AIS vessel tracking data for [Kapsar et al. (2023)](https://link.springer.com/article/10.1007/s10584-023-03568-3). For more details on methodology, please see the manuscript text. For questions, please email kelly.kapsar@gmail.com.
